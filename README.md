# TrendPulse - Part 1: Python Foundations

## Project Overview
TrendPulse analyses YouTube trending video records using Python fundamentals.

## Dataset
Countries: US, GB, IN
Total records: 46,230

Note: The supplied dataset is synthetic instructor-provided reference data, not real-world YouTube data.

## Tools
Python, Pandas, NumPy, Matplotlib, Google Colab.

## Concepts Covered
- Lists, dictionaries, tuples and sets
- Loops and conditional statements
- Functions and default arguments
- Variable scope
- String manipulation
- Rule-based classification
- Code refactoring

## Data Cleaning
- Numeric value conversion
- Missing value handling
- Boolean conversion
- Date parsing

## Classification
Viral Hit, Steady Performer, Divisive, Low Engagement and Unrated.

## Validation
US: 16,080
GB: 15,075
IN: 15,075
Total: 46,230

## How to Run
1. Open the notebook in Google Colab.
2. Upload and extract the dataset.
3. Run all cells from top to bottom.

## Conclusion
Part 1 demonstrates core Python concepts for processing and analysing trending video records.
